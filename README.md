# Computer Simulation

Open `index.html` in a browser to preview the site. The whole site lives in that file and requires no build tools. Google Fonts are optional and the site falls back to system fonts.

## Publish on GitHub Pages

1. Create a public repository owned by the course organization. Name it `ORG.github.io`, replacing `ORG` with the organization’s GitHub handle.
2. Upload `index.html` to the root of `main` and commit it. You can also upload the optional `.nojekyll` and this README.
3. Open **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**, choose **main** and **/ (root)**, then save.
4. When deployment succeeds, open `https://ORG.github.io/`. Check the repository’s **Actions** tab for build status.

[GitHub Pages documentation](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

## Update the course

- In the Teaching assistants section of `index.html`, duplicate an entry in the TA list to add another assistant. Mohamad Marandi is listed separately as Head TA.
- In Past semesters, duplicate a `details` entry to add a term. Use `summary` for the semester, and list that semester's TAs and links to any available materials. Current entries are partial and link to their public sources.
- The syllabus and assessment come from slides 2–4 of the provided Chapter One introduction. The textbook link goes to Pearson.
